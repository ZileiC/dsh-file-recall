# File Recall

用这个 skill 处理「只记得旧资料的零散细节、说不清文件或页码」的请求。用户要的是**定位 + 证据**：文件路径、页/幻灯片/段号，以及一段能让他「认出来」的原文。不是摘要。

## 何时使用

- 用户说「以前有个方案/那份 PPT/某个客户的东西」，但记不起文件名。
- 用户用画面、年份、项目名、一两个关键词描述，而不是精确标题。
- 用户要找「某一页角落里的一句话」。

## 工作流

1. **先看索引**：调用 `file_recall_index`（`action: "status"`）。
   - 若 `roots` 为空：先问用户「资料放在哪个文件夹」（一次只问一个），
     然后调用 `action: "configure", roots: ["该文件夹绝对路径"], confirm: true`，再继续。
   - 若 `pending > 0` 或从未建库：
     - 先 `action: "sync"` 扫描根目录；
     - 再反复 `action: "build"`，直到返回 `done: true`；
     - 把进度告诉用户，不要假装瞬间完成。
2. **用用户原话搜索**：调用 `file_recall_search`，query 直接传用户描述（年份、类型、画面、项目名都保留）。第一次不要自作主张改写成「更好」的查询。
3. **读候选页**：对最相关的 1–3 个命中调用 `file_recall_evidence`，读原文。搜索结果只是线索，不是证据。
4. **回答**：最多给 3 个候选，每个写成：
   `路径 — 第 N 页/幻灯片/段 — "逐字引文" — 为什么匹配`。
   明确标出匹配强度（`content` / `path` / `content+path`）与是否需要用户确认。

## 证据纪律

- 页码、幻灯片号、段号**只能来自工具返回的 `page`/`block`/`locator`**，不许模型自己数。
- 引文必须从 `file_recall_evidence.text` 里**逐字复制**；不要改写、不要补全。
- 搜索返回的 `snippet` 只能用来判断相关性，不能直接当引文；引用前必须读 evidence。
- `degraded: true`（查询扩展降级为纯词法）或 `relaxed: true`（严格查询放宽为 OR）只说明检索走了兜底/放宽，不代表结果不可靠；仍以 evidence 为准。
- OCR 文本可能有识别错误（`ocrSource` 非空时）；引用时要提醒用户「这是 OCR 结果」。
- 找不到就承认找不到——**绝不编造文件、页码或引文**。

## 空态处理

- 如果 `hits` 为空：直接说「这次没找到匹配」，不要拿相近但不相关的结果凑数。
- 给出一个收窄建议：年份、目录、文件类型，或换一个记得更清楚的词。
- 如果索引未建/索引范围不对：先解释原因并引导建库，不要反复空搜。
- 如果用户只是模糊记得、连关键词都没有：先问一个最有区分度的问题（哪一年 / 哪个客户 / 大概什么类型），一次只问一个。

## 反馈

用户确认或纠正候选后，调用 `file_recall_feedback`：

- 确认：`{ action: "record", verdict: "hit", chunkId, query }`
- 纠正：`{ action: "record", verdict: "partial" | "wrong", chunkId, query, correction: "原词=标准词" }`
- 查看历史：`{ action: "list" }`；查看学到的词：`{ action: "synonyms" }`

学到的同义词只存在本地，并会在下次搜索时以 `appliedSynonyms` 标出来源。

**不要为了记反馈而追问。** 插件已经按对话走向自动推断：用户接着追问/换说法重问 = 上一条没找到；转去问别的 = 上一条算找对了；用户沉默则不记。你只在用户**开口表态**时才调用，例如「对，就是这页」→ `hit`，「不是这个」→ `wrong`。

两种来源在库里分开：`stated`（用户说的）才会进入同义词表，`inferred`（推断的）只用于统计。这防止插件靠自己的猜测越学越偏。

## 记忆与记忆层

`file_recall_index { action: "status" }` 的 `memory` 字段是这块的唯一事实来源：`total / pending / hit / wrong / partial / stated / inferred / synonyms / feedback`。

- 用户问「你是不是记住了什么 / 用起来会变准吗」：读 `memory` 回答，不要空口承诺。
- `total` 很大但 `stated` 很小 = 记忆主要靠推断，说明数据可信度有限，如实说。
