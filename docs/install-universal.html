macOS 安装指引 · 七步 · 约 10 分钟

让本地的文件能被随口问出来

写给谁

这份指引面向会用 Mac、但没接触过命令行的人。全程点按、拖拽、复制粘贴，不需要打开终端。

整个流程装两样东西：DeepSeek Harness（桌面应用）和一个本地文件检索插件。 索引和检索都在本机完成，文件不上传。

中途出错先往下翻，遇到卡住的地方，把屏幕截图发给出指引给你的人。

01

下载

打开 www.deepseek.com/harness/

按钮上写的是「下载 Windows 版」。不要直接点它。它右边的小箭头才是 Mac 版入口， 在展开的菜单里选macOS（Apple 芯片）。

选完浏览器开始下载，下载列表里会出现一个 .dmg 文件。

确认芯片型号：点左上角苹果标志，选「关于本机」，看「芯片」一行。 显示 Apple M1 / M2 / M3 / M4 这类，选 Apple 芯片版。

若菜单里只有 macOS（Apple 芯片），而你用的是更早的 Intel 机型，先不要下载，告知发指引给你的人。

02

移到「应用程序」

双击下载好的 .dmg，弹出一个窗口。把左边的图标拖到右边的「应用程序」文件夹上，松手。

拖完关掉这个窗口就行。

03

打开并登录

在「启动台」或「应用程序」里找到它，双击打开。登录页提供微信扫码，用手机扫一下即可。

首次打开可能被 Gatekeeper 拦截，提示来自身份不明的开发者。

去 系统设置，进入隐私与安全性，向下滚动，点「仍要打开」，再确认一次。

04

安装检索插件

复制下面这段，粘贴到对话框里发送。安装由 agent 完成，不需要手动操作。

帮我装一个插件，从这个地址装：
https://github.com/ZileiC/dsh-file-recall

装好以后告诉我：装在哪、有没有报错。

中途询问是否允许访问文件时，选允许。

如果它报找不到 node、npm 或 git：这台机器缺构建工具，不是安装出错。

换下面这段，让它改装自带依赖的离线包。首次安装会请求网络访问，之后走本地。

这台电脑没装 node 和 npm。请用离线包装：

https://github.com/ZileiC/dsh-file-recall/releases/latest
下载 zip，解压得到 dsh-file-recall 文件夹，从这个文件夹装，不要联网装依赖

两种都失败，把对话截图留档即可，不必反复重试。

05

建立索引

在对话框里说：帮我把资料建成索引。

它会扫描指定的文件夹并记录内容。文件多时需要等待，期间不要关闭窗口。

它若问资料在哪个文件夹，而你也不确定位置，回它：

我不知道在哪个文件夹，你帮我找找
06

等待完成

结束时它会报出收录的文件数量。看到这条提示就算建好了。

首次建立最慢，之后每次查询是秒级。

07

开始检索

用日常说法描述你记得的片段即可，不需要记文件名：

帮我找一下去年那份课程笔记
那个讲矩阵的课件在哪
上次那份合同，带签字的那版

结果会给出文件路径、页码和对应原文，方便核对。

如果结果不对，直接说「不是这个」。它会记下这次纠正，同类问题的后续检索会更准。

出错时：截图保留现场，连同哪一步出的问题一并记录。不需要排查英文报错，也不需要重装。

索引与检索全部在本机进行，文件不会上传到服务器。

除第 1 步的官网截图外，其余配图是按动作画的示意图，不是真实界面截图。
