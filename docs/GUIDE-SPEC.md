# 给爸爸的安装指南

> 这不是给 agent 看的文档，是给一个**从来没接触过 AI 助手**的人看的。
> 改写这份文档的人请守住三条：每屏只讲一件事；每步只有一个动作；不出现任何命令行。

## 读者画像（写文案时始终对着这个人说话）

- 五十多岁，用 Mac 十来年，会打开"文稿"、会拖文件，**没开过"终端"**。
- 没听说过"插件""索引""命令行"，但看得懂"帮我找文件"。
- 遇到英文报错会直接放弃，然后打电话给儿子。所以：**任何他看不懂的东西都不许出现在他面前**。

## 三条铁律

1. **他永远不碰命令行。** 装 Node 这一步交给他儿子，或者交给 agent。指南里只写"这一步让你儿子远程弄"。
2. **每步一个动作。** 一步里出现两个操作（比如"下载并安装"）就要拆成两步。
3. **图比字多。** 每个步骤必须配一张截图，截**屏幕上他需要看的那一块**，不要整屏。

## 步骤骨架（已确认）

| 步骤 | 他要做的动作 | 截图位置 |
|---|---|---|
| 0 | 读一段「这是谁写的」：陈孜磊手下的打工者，被派来跑外勤教他装 | 不需要 |
| 1 | 打开 `https://www.deepseek.com/harness/`，点 Mac 版下载 | 下载页按钮 |
| 2 | 把图标拖进「应用程序」 | 拖拽那一瞬间 |
| 3 | 打开，微信扫码登录 | 登录页二维码 |
| 4 | **（跳过）插件安装由 agent 完成**，他只需要复制一段话 | 不需要 |
| 5 | 在对话框里说「帮我把资料建成索引」 | 输入框 |
| 6 | 等他看到"完成" | 进度状态 |
| 7 | 真正开始用 | 一次真实问答 |

**下载地址只说这一个**：`https://www.deepseek.com/harness/`。
不要再写 `deepseek.com` 首页——他会在首页里找不到下载入口。

## 给 agent 的安装指令（第 4 步用，他只需要复制粘贴）

> 这段印在指南里，他儿子远程时直接发给他，他复制粘贴给 agent 即可。

```
帮我装一个插件，从一个 GitHub 项目装：
https://github.com/ZileiC/dsh-file-recall

装好后告诉我插件装在哪、有没有报错。
```

## 索引怎么建（他自己的话就能说）

他不需要知道文件夹在哪。两句备用话：

- 正常情况：**"帮我把资料建成索引"**
- 不知道在哪：**"我不知道资料在哪个文件夹，你帮我找找"**

第二句是关键：agent 有权限扫盘，能自己翻出来，不用他回答路径。

## 截图占位

正文里所有图片位置都已留好 `<figure>` 占位框，旁边写着"这张图应该拍什么"。
拍照的人（儿子）按那句提示截，尺寸按 16:10，存成 `docs/img/step-01.png` 这样的名字。
