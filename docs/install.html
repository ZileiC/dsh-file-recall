安装指南 · 大约 10 分钟

装一个会帮你找文件的助手

装好以后，你可以在对话框里随口说一句「帮我找去年那个体检报告」， 它会告诉你文件在哪、在第几页。下面七步，每一步只有一个动作。

第一步

下载

打开 deepseek.com， 找到写着 下载 DeepSeek Harness 的按钮，点一下。

它选 Mac 版。下载的东西会出现在浏览器的下载列表里，名字以 .dmg 结尾。

找不到下载按钮的话，直接跟儿子要链接——他会把当天有效的下载页发给你， 照着点就行，不用自己在网站里找。

第二步

把它放进"应用程序"

双击下载好的文件，会弹出一个窗口， 把左边的图标拖到右边的"应用程序"文件夹上，松手。

拖完就可以把那个窗口关掉了。

第三步

打开，用微信登录

在"启动台"或"应用程序"里找到它，双击打开。 登录页面会有微信扫码的选项，用手机微信扫一下就进微信。

第一次打开，Mac 可能会拦一下，说这个程序来自身份不明的开发者。

这时候去 系统设置 → 隐私与安全性，往下滑， 看到一句「仍要打开」，点它，再确认一次就行。

第四步

装那个帮你找文件的功能

这一步不用你做。把下面这段话，整段复制，粘进对话框，发出去。

帮我装一个插件，从这个地址装：
https://github.com/ZileiC/dsh-file-recall

装好以后告诉我：装在哪、有没有报错。

它会自己下载、自己安装。中途如果它问你要不要允许访问文件，选允许。

如果它说找不到 node、或者报了看不懂的英文： 把对话截图发给儿子，让他远程弄。这一步卡住是正常的，不是你的问题。

第五步

让它把你的资料过一遍

在对话框里说一句：帮我把资料建成索引。

它会开始扫你的文件。文件多的话要等一会儿，别关窗口，让它跑完。

如果它问「资料在哪个文件夹」，你不知道在哪儿也没关系，直接回它：

我不知道在哪个文件夹，你帮我找找

第六步

等它说"好了"

它跑完会告诉你建了多少个文件。看到这句话就成了。

第一次可以慢，以后再问就是几秒钟的事。

第七步

开始用

就像跟人说话一样，把你记得的一点点细节说出来。比如：

帮我找一下去年那份体检报告
那个讲矩阵的课件在哪
上次那份合同，带签字的那版

它会给你文件在哪、在第几页，还会把那段原文摘出来给你核对。

如果它找错了，直接告诉它「不是这个」，它会记住，下次更准。

卡住了怎么办：把屏幕上你看到的东西拍下来发给儿子就行。 不用自己琢磨英文报错，也不用重装。

你的文件全程留在自己电脑上，不会上传到任何地方。
