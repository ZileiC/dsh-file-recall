# 配图说明

指南有两个版本：

| 文件 | 用途 | 图片 |
|---|---|---|
| `docs/install.html` | 编辑用（仓库内，和 `img/` 一起打开） | `src="img/…"` 相对路径 |
| `docs/install-standalone.html` | **发给别人用**（单文件，手机也能看） | base64 内嵌 |

改完 `install.html` 后跑一次：

```bash
node scripts/bundle-guide.mjs
```

就会重新生成单文件版本（500 KB 左右，0 个外部引用）。

> 为什么要有单文件版：只发 HTML 不带 `img/` 文件夹时，相对路径全部失效——手机上就是「图片不显示」。内嵌后一个文件到哪都能开。

## 六个示意图（不占图片文件）

第 2–7 步的图是内联 SVG，画的是**读者要做的动作**（拖拽、扫码、粘贴、等待、提问），
不是伪造的 macOS 界面。改文案或改图形都直接改 `install.html` 里对应的 `<svg>`。

## 以后可选：换成真截图

有了真机截图，可以把对应 `<div class="plate">…<svg>…</svg></div>` 整块换成：

```html
<div class="plate"><img src="img/step-02.png" alt="安装窗口，图标拖向应用程序文件夹"></div>
```

然后重跑 `node scripts/bundle-guide.mjs`。不换也完全能用。
