# 配图说明

指南页面（`docs/install.html`）只引用两张真图，其余六步用的是画在页面里的**动作示意图**。

## 已在仓库里的两张（2026-11-15 由 ZileiC 从官网截取并裁切）

| 文件 | 用在哪 | 内容 | 尺寸 |
|---|---|---|---|
| `hero-shot.png` | 页首右侧的「产品肖像」 | 官网下载页：标题 + 下载按钮 + 展开菜单 + 一点产品窗口 | 1318×823 |
| `step-01-menu.png` | 第 1 步正文里 | 按钮 + 小箭头 + 展开菜单的特写 | 896×560 |

两张都来自同一张原图，按 16:10 裁切；重新截取时保持 16:10 即可替换。

## 六个示意图（不占图片文件）

第 2–7 步的图是内联 SVG，画的是**读者要做的动作**（拖拽、扫码、粘贴、等待、提问），
不是伪造的 macOS 界面。改文案或改图形都直接改 `install.html` 里对应的 `<svg>`。

## 以后可选：换成真截图

有了真机截图，可以把对应 `<div class="plate">…<svg>…</svg></div>` 整块换成：

```html
<div class="plate"><img src="img/step-02.png" alt="安装窗口，图标拖向应用程序文件夹"></div>
```

不换也完全能用——示意图已经把动作说清楚了。
